# AtTime

简洁优雅的 macOS 桌面时钟，显示北京时间，支持中国农历与二十四节气，并自动按节气分界展示四季。

## 功能简介
- 显示北京时间（`Asia/Shanghai`），每秒刷新
- 时间布局对称：`时 : 分 : 秒`，三色区分，美观易读
- 日期显示在时间下方：`YYYY-MM-DD`
- 农历显示：`干支年 月日`（示例：`乙巳年 十月初三`）
- 节气与四季：
  - 当天为节气时，显示：`今日立冬 / 今日小雪 / ...`
  - 非当天节气时，按节气分界显示四季：立春→春季、立夏→夏季、立秋→秋季、立冬→冬季
- 渐变背景，窗口可最大化，自适应填充背景

## 系统要求
- macOS 10.13 及以上

## 下载与运行
- 推荐方式：到 Releases 页面下载打包好的 `AtTime.zip`，解压得到 `AtTime.app`，双击运行
  - Releases 地址：https://github.com/wujupeng/attime/releases 最新版本 `v1.0.1`

## 源码构建
在项目根目录执行：
- `make` 构建二进制 `AtTime`
- `make bundle` 生成 `AtTime.app`
- `make zip` 打包生成 `AtTime.zip`
- `make run` 直接运行程序

## 显示规则说明
- 农历：基于中国农历日历（天干地支纪年），示例：`乙巳年 十月初三`
- 节气：采用近似算法计算 1900–2100 年节气日期
- 四季划分：以四个节气分界（立春、立夏、立秋、立冬）为区间边界

## 常见问题
- 无法打开应用：将 `AtTime.app` 放到「应用程序」目录或右键选择「打开」以绕过 Gatekeeper 限制
- 节气显示与官方略有差异：算法采用近似模型，极少数年份可能相差 1 天
